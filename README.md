
TikTok-Style Animated Buttons

Description
This project simulates the interactive "Subscribe → Like → Share → Profile" sequence seen in social media videos like TikTok. The animation features:  
- Futuristic button animations  
- Finger click interactions  
- Profile image display (`tok.jpg`)  
- Username display with verify badge  
- Step-by-step sequential interaction

Features
- *Subscribe Button*: Appears first and animates on click  
- *Like Button*: Appears after the subscribe button is clicked  
- *Share Button*: Appears after the like button is clicked  
- *Profile Display*: Shows after all buttons are clicked  
- *Username & Badge*: Displays under the profile image  

Technologies
- HTML5  
- CSS3 (Animations & Transitions)  
- JavaScript (Event Handling & Sequencing)  

Installation
1. Clone the repository:  
   ```bash
   git clone https://github.com/your-username/tiktok-button-animation.git
   ```  
2. Open `index.html` in your browser.  
3. Make sure the image `tok.jpg` is in the same folder as your HTML file.  

Usage
1. Click the *Subscribe* button to start the animation.
